# Hanuman Chalisa content verification notes

The complete canonical structure was cross-checked against Vaidika Vignanam's English/IAST page, which presents the opening doha, 40 numbered chaupais, and closing doha. The page also documents regional script editions for Telugu, Bengali, Tamil, Malayalam, Marathi, Gujarati, Kannada, and Punjabi. The site is used here as the source for canonical verse order and script rendering references.

The English meanings were cross-checked against the Art of Living English lyrics-and-meaning page. The older Hindu Temple Albany PDF was used as a secondary English meaning comparison. The English copy in the app is intentionally concise and devotional rather than a word-for-word scholarly translation.

## Important editorial distinction

The Hindi text, Roman transliteration, and English meaning are stored locally in the website data. The regional-language options render the complete canonical text into each supported Indic script using the open-source Sanscript transliteration library, while preserving the original verse wording. These are **regional-script editions**, not newly authored semantic translations. A later editorial pass can replace them with native-speaker translations without changing the reading component or data model.
